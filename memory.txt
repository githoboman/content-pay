1. PROJECT SUMMARY & CORE PURPOSE
--------------------------------------------------------------------------------
ContentPay is a decentralized micropayment and content registry platform enabling:
- Human creators and autonomous AI agents (Agent OS / ERC-8004) to publish articles.
- Readers to unlock locked content with sub-second finality (~0.75s block time).
- Ultra-low transaction fees (~$0.06), making micropayments (< $1.00) viable.
- Automatic revenue distribution: 97% directly to author wallet, 3% to platform treasury.
- Multi-token support: Native BOT / tBOT and ERC-20 tokens (e.g. USDC, USDT).


2. MIGRATION FROM STACKS TO BOT CHAIN
--------------------------------------------------------------------------------
Legacy Architecture:
- Stacks Blockchain, Clarity contracts (`content-registry.clar`, traits, `mock-*.clar`).
- Bitcoin settlement with ~5s to ~10m block times.
- `@stacks/connect`, `@stacks/transactions`, Leather / Xverse wallets.

BOT Chain Architecture (Current):
- EVM-compatible Layer 1, Solidity `^0.8.20`.
- Fast consensus: ~0.75-second block finality.
- Native compatibility with MetaMask, Rabby, Coinbase Wallet, EIP-1193.
- `ethers.js` v6 provider and signer.
- Full compatibility with BOT Chain Agent OS and ERC-8004 verifiable agent identities.


3. SMART CONTRACTS SPECIFICATION (`contracts/`)
--------------------------------------------------------------------------------
A. `ContentRegistry.sol`:
   - `publishArticle(title, contentUri, priceUsdCents, category)`:
     Registers article on-chain, emits `ArticlePublished`.
   - `updatePrice(articleId, newPriceUsdCents)`: Author only.
   - `setActive(articleId, active)`: Author only.
   - `purchaseWithBOT(articleId) payable`:
     Calculates required BOT amount via `calculateBotAmount(priceUsdCents)`.
     Transfers 97% to author, 3% to platform treasury.
     Refunds any excess `msg.value` automatically.
     Emits `ArticlePurchased`.
   - `purchaseWithToken(articleId, token)`:
     ERC-20 payment (e.g., MockUSDC with 6 decimals).
     Transfers tokens from reader: 97% to author, 3% to platform treasury.
   - Read & View Functions:
     - `getArticle(articleId)` -> Article struct
     - `hasPurchased(articleId, reader)` -> bool
     - `getPurchasedArticles(reader)` -> uint256[] array of all unlocked IDs
     - `getArticlesByAuthor(author)` -> uint256[]
     - `getPlatformStats()` -> totalArticles, totalPurchases, totalRevenueUsdCents
     - `calculateBotAmount(priceUsdCents)` -> uint256 in wei

B. `MockUSDC.sol`:
   - 6-decimal ERC-20 token with `mintFaucet(recipient, amount)` for Bohr Testnet.

5. FRONTEND ARCHITECTURE (`frontend/`)
--------------------------------------------------------------------------------
Technology: Next.js 16 (Turbopack, App Router), React 19, TailwindCSS, Ethers.js v6

Pages & Routes:
- `/` (`app/page.tsx`):
  Hero highlighting BOT Chain features (~0.75s blocks, ~$0.06 fees, Agent OS),
  key metrics, and trending feed preview.
- `/browse` (`app/browse/page.tsx`):
  Marketplace to explore articles by category with search and instant unlock buttons.
- `/publish` (`app/publish/page.tsx`):
  Creator studio with AI sample autofill and on-chain publishing.
- `/article/[id]` (`app/article/[id]/page.tsx`):
  Article details, dual payment selector (tBOT / USDC), instant unlock, and full content.
- `/my-library` (`app/my-library/page.tsx`):
  Displays all articles unlocked by the connected EVM account.
- `/test-publish` (`app/test-publish/page.tsx`):
  1-Click publishing testbench for Bohr Testnet.
- `/test-buy` (`app/test-buy/page.tsx`):
  1-Click purchasing testbench for Bohr Testnet.

Context & Libraries:
- `context/WalletContext.tsx`:
  Web3 context managing accounts, chain ID, live tBOT balance, and network switching.
- `lib/botchain.ts`:
  Bohr Testnet (968) and BOT Mainnet (677) parameters, RPC URLs, switchOrAddNetwork helper.
- `lib/abi.ts`:
  Human-readable ABIs for ContentRegistry and ERC20.
- `lib/config.ts`:
  Active network configuration export.
- `types/ethereum.d.ts`:
  Window.ethereum global type declarations.
